# BiliPicks · 从好奇到会看（小学一年级版）

这是给小学一年级（大约 6～7 岁）孩子用的 BiliPicks 改编版：家长手选 B 站视频，主线 6 关小闯关，看完打卡。没有推荐算法，只播清单里的视频。

本站改编自实践哥 Li 的 MIT 开源项目 [limin112/bilipicks](https://github.com/limin112/bilipicks)，不是原作者的官方站点。原版面向小升初（五六年级～初一），示范站在 <https://minlibuilds.com/bili/>。

## 怎么打开

不需要构建，也不需要注册。任选一种方式即可：

1. 直接用浏览器打开 `index.html`（双击也行）。
2. 在本目录启动一个本地静态服务器，再访问首页和电视版，例如：

```bash
python3 -m http.server 8765
```

然后打开 <http://127.0.0.1:8765/>（网页版）或 <http://127.0.0.1:8765/tv.html>（电视版）。

看完进度、动手任务勾选、深色模式和自动播放都只存在这台设备的浏览器里（键名带 `bilipicks-g1-` 前缀，不会和原版或初中版站点抢同一份记录）。换设备不同步，清除浏览数据会丢。

播放器用的是 B 站官方嵌入播放器，不抓取视频流，默认关闭弹幕。B 站限制站外播放最高约 480P，点「去 B 站看高清」可到 B 站看更高清晰度。到了 B 站以后会出现它自己的推荐，看完请回来，不要顺着推荐往下刷。

电视、投影仪可以用 `tv.html` 的遥控器界面。安卓电视应用的安装方法见原仓库 [`android/`](https://github.com/limin112/bilipicks/tree/main/android)。

## 路线概要

路线名：**从好奇到会看**，一共 6 关，都是现在就能看的小片子。每一关最后有一个在家里做的小任务，不用打开 Google、python.org 或 Scratch 编辑器（这些网站在国内常常打不开，对一年级也太难）。

1. **听故事，认字** — 成语小故事、甲骨文怎么「画」出来、一起写「人」「大」「天」。任务：把今天的故事讲给家里人听。
2. **身边的小动物** — 熊猫宝宝、长颈鹿、小河马、小企鹅。任务：看天上的云像什么，再数一数能看见几只小鸟。
3. **走进博物馆** — 霸王龙和「匹诺曹」恐龙、四羊方尊、骨笛、陶狗。任务：画下最喜欢的一件宝物或一只恐龙。恐龙骨架比较大，请坐在旁边一起看。
4. **为什么会这样** — 橘子为什么会浮、水流弯一弯、牛奶光柱、家里看彩虹、钢琴怎样发声。任务：和爸爸用水盆猜一猜哪些东西会浮、哪些会沉。不要把电器放进水里。
5. **动手做一做** — 纸花、纸陀螺、折扇、纸蚕宝宝；鲁班锁只看、不要模仿刀和锯。任务：和爸爸一起折纸飞机或纸青蛙，数一数能飞几下。
6. **坐下来看完一条** — 故宫的雪、园林四季、睡莲；稍长的「看见声音」「香蕉操作手机」请周末陪看。任务：今天只看一条，看完告诉爸爸记住了什么。

分类浏览里还有更多官方短片。中国教育电视台、央视纪录这两个频道里还有课堂、招生或战争题材，请只打开清单里的那几条。

## 给家长的提醒

- 请尽量坐在孩子旁边看。标了「请爸爸陪看」或「请一起看」的，是稍长、有大骨架，或需要动手的片子。
- 这不是逐片审过的儿童白名单：视频按标题、简介和官方来源挑选，年龄是编辑建议，不是官方分级。
- 动手实验请家长在场。不要模仿刀、锯和火，也不要把水、水果弄到电器上。
- 点「去 B 站看高清」之后会出现 B 站自己的推荐，建议关掉自动连播。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面、样式和交互逻辑 |
| `tv.html` | 电视版：遥控器界面，数据也读 `data.js` |
| `data.js` | 所有内容：视频、成长路线、频道名单、策展人信息（必须保持 `const DATA = {...};` 单行，以便 `update.py` 读写） |
| `update.py` | 维护脚本：检查失效视频、补封面和时长（只用 Python 标准库） |

加视频或检查失效：

```bash
python3 update.py add BV1xxxxxxxxx --cat 科学好奇 --age 6 --reason "为什么推荐"
python3 update.py --check    # 只出报告，不改文件
```
